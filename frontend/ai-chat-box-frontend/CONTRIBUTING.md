# Contributing

We welcome contributions to the AI Chat Box project. Follow these steps:

1. **Fork the repository** and clone your fork.
2. **Create a new branch** for your feature or bug fix:
   ```bash
   git checkout -b my-feature
   ```
3. **Install dependencies**:
   ```bash
   npm install
   ```
4. **Run the development server**:
   ```bash
   npm run dev
   ```
5. **Make your changes** and ensure the app still builds:
   ```bash
   npm run build
   ```
6. **Commit your changes** with clear messages and push to your fork.
7. **Open a Pull Request** targeting the `main` branch of the upstream repository.

Please follow the existing code style and run any available linting or formatting tools before submitting. Issues and feature requests can be opened on the GitHub repository.
